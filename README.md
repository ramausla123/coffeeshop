# Coffee Shop Starter Monorepo

Starter monorepo containing a Next.js PWA frontend and a NestJS backend.

Quick start (install deps separately in each app):

Frontend:

```bash
cd apps/frontend
npm install
npm run dev
```

Backend:

```bash
cd apps/backend
npm install
npm run start:dev
```

Ports:
- Frontend: http://localhost:3000
- Backend: http://localhost:4000
